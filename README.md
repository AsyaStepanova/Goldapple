# Тестовое задание — аналитик данных по ценообразованию

Решения тестового задания по анализу цен, продаж, скидок и маржинальности. Задания 1–3 выполнены на Python с использованием pandas, задания 4–5 — на SQL для ClickHouse.

## Содержание

| Файл | Задание | Описание |
| --- | --- | --- |
| `01_Конкуренты_и_наценки.ipynb` | 1 | Применение правил наценки, сравнение цен с конкурентами, расчёт возможных скидок с ограничением по маржинальности. |
| `02_Скидки_и_продажи.ipynb` | 2 | Анализ исторической зависимости среднедневных продаж от размера скидки. |
| `03_Бренды_и_маржинальность.ipynb` | 3 | Сравнение выручки, валовой прибыли и маржинальности брендов за недели 14 и 15. |
| `sql/04_1_Товары_и_остатки.sql` | 4.1 | Продажи, средняя цена, среднемесячный объём и остатки по товарам. |
| `sql/04_2_Топ_5_брендов.sql` | 4.2 | Топ-5 брендов по выручке за последний полный месяц и сравнение с предыдущим месяцем. |
| `sql/05_WAU.sql` | 5 | Расчёт WAU по дням на основе логов посещений. |
| `Тестовое_задание_Data_аналитик_ЦО_2025_2(1).xlsx` | Исходные данные | Оригинальный Excel-файл с условиями и исходными таблицами. |

## Как запустить ноутбуки

1. Установить Python и JupyterLab.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Открыть папку репозитория в JupyterLab.
4. Запустить нужный `.ipynb`, выполняя ячейки последовательно сверху вниз.

Все три ноутбука читают исходные данные непосредственно из Excel, расположенного в корне репозитория. Дополнительные CSV-файлы не нужны.

## SQL

SQL-файлы написаны для ClickHouse и используют таблицы `dwh.sales`, `dwh.products`, `dwh.stock` и `dwh.site_activity`, описанные в задании. Для выполнения нужен доступ к базе с этими таблицами; исходный Excel их не содержит.

## Примечания к расчётам

- В расчёте цен и скидок учитывается нижняя граница маржинальности 10%.
- В анализе продаж при скидках сравниваются исторические среднедневные значения. Наблюдаемая зависимость сама по себе не доказывает причинный эффект скидки.
- Общая маржинальность рассчитывается как отношение суммарной валовой прибыли к суммарной выручке, а не среднее процентов по брендам.
